# Redstropolis

Redstropolis is a creative-focused Minecraft 1.7.10 modpack built around realistic city building and electrical simulation. The pack is designed for players who want to design modern cities, power grids, and infrastructure without survival constraints.

At its core, Redstropolis focuses on the Electrical Age mod by jrddunbr, providing a deep and realistic electricity system that goes far beyond vanilla Redstone.

> [!IMPORTANT]
> This modpack is designed for creative mode only. Many world generation features have been disabled to improve performance!

## Installation

### Option 1: Prism Launcher (Recommended)

1. Download the Prism Launcher–compatible file from the [Releases page](https://github.com/Justus0405/Redstropolis/releases).
2. Open Prism Launcher.
3. Click Add Instance.
4. Choose Import, then select the downloaded file.
5. Launch the instance.

### Option 2: CurseForge (Manual Import)

1. Download the CurseForge-compatible file from the [Releases page](https://github.com/Justus0405/Redstropolis/releases).
2. Open the CurseForge launcher.
3. Click Create Custom Profile or Import.
4. Select the downloaded file.
5. Launch the profile.

## Known Issues

- Immersive Railroading + Addons can break the texture atlas, causing other 3D model textures to appear as the fire texture in the inventory. These mods have sadly been disabled for now.
